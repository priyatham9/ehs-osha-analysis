# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please email priyatham9@gmail.com with the following information:

- Description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact
- Any suggested fix

We will make a best effort to respond within 14 days of your report.

## Scope

This security policy covers vulnerabilities in the code of this repository. It does not cover vulnerabilities in the public datasets or data that this code processes.
