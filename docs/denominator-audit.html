Method / bounded conclusions

Influence is not invalidity.

The pooled rate weights each filing by reported hours. This tool applies the same inclusive hours-per-employee screen in both selected years, then directly recomputes leave-one-out changes for every included record. Single-record reversals compare the signs of the original and leave-one-out differences; a zero difference is not a reversal.

Exclusion scenarios recompute the pooled rate after all selected records are removed. Their effects need not add. This is a sensitivity analysis, not a corrected estimate, probability sample, causal analysis, or judgment about data quality. Rates can also change because the reporting population changes.

Calculations use standard floating-point arithmetic; differences smaller than numerical precision may not be resolved. Missing or invalid required values stop the audit instead of silently dropping rows. A year with zero remaining hours has no defined rate. A zero baseline rate has no defined percentage change; the absolute rate difference remains available.
