Form 300A filing checker

Enter the figures from one OSHA Form 300A. The check runs in your browser; nothing is sent anywhere. It applies the same rules as the plausibility screen in ehs-osha-analysis, read from the shared file plausibility_rules.json.

This is a screen, not an audit. It flags filings whose numerator and denominator cannot both be right; it does not say which field is wrong. Bounds and their rationale are in the repository README and src/ehs_osha/quality.py. Column letters follow the ITA field names in the repository; confirm against your form.
